# Vendor Marketplace 🛍️

A complete multi-vendor e-commerce platform built from scratch by a self-taught developer. This project demonstrates full-stack development skills with modern technologies and real-world e-commerce features.

## 🚀 What This Project Does

A fully functional online marketplace where multiple sellers can open their stores and customers can shop from all sellers in one place. Think of it like a mini-Amazon or Etsy built by one developer.

### 🏪 Real Marketplace Features
- **Multiple Sellers** - Different vendors can register and sell products
- **Smart Shopping Cart** - Add items from different sellers, apply coupons, see real-time prices
- **Secure Payments** - Integrated with Stripe and JazzCash for real transactions
- **Order Management** - Complete order tracking from placement to delivery
- **Admin Control** - Platform owner can manage everything and control payments

### 🤖 AI Shopping Assistant
- **Chatbot Helper** - AI assistant that helps customers find products

### 🔐 Security & Verification
- **OTP Login** - Secure login with one-time passwords sent via email
- **Email Verification** - Sellers must verify their email before selling
- **Role Protection** - Different permissions for customers, sellers, and admin

### 🎫 Smart Discount System
- **Coupons** - Create discount codes with rules
- **Automatic Calculations** - System finds the best discount for you
- **Multi-seller Support** - Discounts split fairly between sellers

## 🛠️ Technologies I Used

### Backend (My Strength)
- **Java + Spring Boot** - Main server framework
- **Spring Security** - Handles login and permissions
- **PostgreSQL** - Database to store everything
- **Redis** - Fast caching for better performance
- **RabbitMQ** - Handles email sending in background

### AI & Payments
- **Spring AI** - Powers the shopping assistant
- **Stripe API** - Processes credit card payments
- **JazzCash API** - Local payment method support
